# 薬学クイズ（授業資料から作る理解度確認アプリ）

授業資料をフォルダに入れておくと、Claude が内容を読んで**理解度確認クイズ**（4択・○×・一問一答・国家試験形式）を作り、**スマホのアプリ**で解けるようになります。

```
PC: 薬学部授業資料/ に資料を入れる
      ↓ 毎日21時・PCにログインしたとき（自動）／いつでも（手動）
PC: Claude が資料を読んで問題と解説を作る → パスワードで鍵をかける
      ↓
GitHub（ネット上の倉庫）→ スマホのアプリに反映（オフラインでも解ける）
```

## 公開されるもの・されないもの

| GitHub に送る（公開） | 送らない（この PC の中だけ） |
|---|---|
| アプリの画面のプログラム（`docs/`） | 授業資料（`薬学部授業資料/`） |
| パスワードで鍵をかけた問題データ | 鍵をかける前の問題（`quiz-bank/`） |
| 処理用のプログラムと手順書 | パスワード・合鍵（`.secrets/`） |

鍵をかけた問題データは、パスワードを知らない人には意味のない文字の羅列にしか見えません。

## 最初の準備（1回だけ）

### 1. パスワードを決める
エクスプローラーで作業フォルダを開き、**`パスワードを設定.cmd`** をダブルクリックして、スマホでアプリを開くときのパスワード（8文字以上）を入力します。入力した文字は `*` で表示されます。忘れないようにメモしてください。
- `.cmd` のファイルは、VS Code の中で開いても動きません（中身が表示されるだけ）。VS Code の一覧で右クリック →「エクスプローラーで表示」を選び、エクスプローラーからダブルクリックしてください。

### 2. GitHub の準備（ブラウザで行う）
1. **新しいアカウントを作る**: https://github.com/signup （すでに別のアカウントでログインしている場合は、ログアウトするか、ブラウザのシークレットウィンドウで開く）
2. **倉庫（リポジトリ）を作る**: 右上の「＋」→「New repository」
   - Repository name: `yakugaku-quiz`（好きな名前でも可）
   - **Public** を選ぶ（無料でアプリを公開するため。中身は鍵がかかっています）
   - ほかは何もチェックせず「Create repository」
3. **合鍵（アクセストークン）を作る**: 右上のアイコン →「Settings」→ 左の一番下「Developer settings」→「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
   - Token name: `yakugaku-quiz`
   - Expiration（有効期限）: できるだけ長く（期限が切れたら作り直します）
   - Repository access: 「Only select repositories」→ 2 で作った倉庫を選ぶ
   - Permissions →「Repository permissions」→ **Contents** を「Read and write」にする
   - 「Generate token」を押し、表示された `github_pat_…` で始まる文字列をコピーする（この画面でしか表示されません）
4. PC で **`GitHubの合鍵を設定.cmd`** をダブルクリックし、コピーした合鍵を貼り付けて Enter
5. VS Code の Claude に「GitHub の準備ができました。アカウント名は ○○、倉庫名は △△ です」と伝える（Claude が最初の送信をします）
6. **公開の設定**: 倉庫のページの「Settings」→ 左の「Pages」→「Build and deployment」で
   - Source: 「Deploy from a branch」
   - Branch: 「main」、フォルダ: 「/docs」→「Save」
   - 1〜2分後に `https://<アカウント名>.github.io/<倉庫名>/` でアプリが開けます

### 3. スマホに追加する
- **iPhone**: Safari で上のアドレスを開く → 共有ボタン（□に↑）→「ホーム画面に追加」→ **ホーム画面のアイコンから開いて**パスワードを入力
- **Android**: Chrome で開く → メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」→ アイコンから開いてパスワードを入力

パスワードは端末に記憶されるので、次からは入力不要です。

### 4. 毎日の自動更新を登録する
**`自動更新を登録.cmd`** をダブルクリックします。毎日21:00と、PC にログインした5分後に、新しい資料がないか確認します。
- 新しい資料がない日は、すぐ終わります（Claude の利用枠は使いません）
- PC の電源が切れていた日は、次に PC を使い始めたときに実行されます
- やめたいときは **`自動更新を解除.cmd`** をダブルクリック

## 毎日の使い方

### 資料の入れ方
```
薬学部授業資料/
  2A1/                ← 学期（2A2, 3S1 … と増やしてよい）
    有機化学Ⅰ/        ← 科目（フォルダ名がそのまま科目名になる）
      第3回.pdf       ← 1ファイル = 1つの資料
      第4回_配布物/   ← フォルダにまとめると、中の写真などをまとめて1つの資料として扱う
        1.jpg
        2.jpg
```
- 対応している形式: PDF・PowerPoint・Word・画像（JPG/PNG）・テキスト
- iPhone の写真（HEIC）は、JPG で保存し直してから入れてください
- ファイル名を変えたり、別の科目に移したりしても、作った問題と学習記録はそのまま引き継がれます

### クイズを今すぐ作りたいとき
- **`今すぐクイズを更新.cmd`** をダブルクリック、または
- VS Code の Claude に **`/quiz-update`**（または「クイズを更新して」）と送る

### スマホアプリ
- **今日のクイズ**: 復習の時期が来た問題と新しい問題を、毎日自動で選びます（問題数は設定で変更可）。「続きを5問」で隙間時間に少しずつ解けます
- **間違えた問題**は、その場でもう一度出題され、翌日にも復習に出ます。正解が続くと、3日後→1週間後→2週間後…と間隔があきます
- **苦手を復習** / **★ブックマーク** / **科目**（資料ごとの「要点の一覧」も見られます）

## 困ったとき

### 問題や解説がおかしい
1. アプリで、その問題の「⚑ 問題を報告」を押して保存
2. 設定画面の「報告をコピー」を押す（LINE などで自分に送ってもOK）
3. VS Code の Claude にそのまま貼り付けて送る → 元の資料を確認して修正されます
4. 直ったら、アプリの設定画面で「報告を消す」

### 学習記録のバックアップ
学習記録はスマホの中だけにあります。機種変更の前などに、設定画面の「書き出す」でファイルに保存し、新しい端末で「読み込む」で戻せます。

### パスワードを変えたい
`パスワードを設定.cmd` で新しいパスワードを設定し、`今すぐクイズを更新.cmd` を実行します。スマホでは次に開いたときに新しいパスワードの入力を求められます。

### 「合鍵が無効か期限切れ」と出た
GitHub で合鍵を作り直し（上の「2. GitHub の準備」の 3）、`GitHubの合鍵を設定.cmd` で保存し直してください。

### PowerPoint・Word の資料が「応答しないため中止しました」となる
PowerPoint・Word を一度も開いたことがないと、最初の確認画面（プライバシーの説明など）が見えないところで出て止まることがあります。スタートメニューから一度開き、出てきた画面を閉じてから終了してください。

### 自動更新がうまくいっているか知りたい
`logs/` フォルダに実行ごとの記録が残ります。完了・失敗は Windows の通知でも知らせます。

## フォルダの中身（詳しい人向け）

| 場所 | 内容 |
|---|---|
| `docs/` | スマホアプリ（GitHub Pages で公開）。`docs/data/` は暗号化済みデータ |
| `scripts/` | 資料の確認（scan）・検査（validate）・暗号化（build）・送信（publish）など |
| `.claude/skills/` | Claude 用の手順書（`/quiz-update`・`/quiz-fix`）と作問ガイド |
| `quiz-bank/` | 平文の問題データ（公開しない） |
| `work/` `logs/` | 一時ファイル・自動実行の記録（公開しない） |
