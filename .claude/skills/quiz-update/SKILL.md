# クイズの作成・更新

## 守ること
- 作業フォルダの外は読むだけ。変更・公開しない。`.secrets/` は読まない。
- コマンドは1つずつ実行する（`cd` や `&&` でつながない）。使うのは `node scripts/…` だけ。
- 引数に「自動実行」とあるときはユーザーに質問できない。迷ったら安全な方を選び、最後の報告に書く。

## 1. 新しい資料を調べる
`node scripts/scan.mjs --json --apply-renames` を実行して結果を読む。
- 対象は `new`（新しい資料）と `changed`（内容が変わった資料）。
- どちらも0件なら `node scripts/build.mjs` → `node scripts/publish.mjs` だけ実行し（変更がなければ何も起きない）、6 の報告へ。
- `misplaced`（置き場所違い）・`unsupported`（未対応の形式）・`missing`（元の資料が消えた）・`duplicates`（同じ内容の重複）は報告に含める。問題データは消さない。

## 2. 資料を読める形にそろえる
`node scripts/prepare.mjs --json` を実行する。PowerPoint・Word は PDF に変換され、10ページを超える PDF は10ページずつに分けられる（Claude はページ指定なしでは10ページまでしか読めず、ページ指定はこの PC では使えないため）。
- 結果の `items`（読むファイルと、その元のページ番号）を資料ごとに使う。
- `problems` がある資料は、読めた部分だけで作るか飛ばし、報告する。

## 3. 資料ごとに問題を作る
- 1資料につき1つのサブエージェント（Agent ツール）に任せ、同時に最大3つまで並行させる。資料が1つだけなら自分で作ってよい。
- サブエージェントへの指示には次をすべて含める:
  - 最初に `.claude/skills/quiz-update/question-guide.md` を読み、そのとおりに作ること
  - scan 結果のその資料の項目（`materialId` `sourceFile` `term` `subject` `hash` `bankFile` `exists`）
  - prepare 結果のその資料の `items`（この順に Read で読む。**pages は指定しない**。`items[].pages` が元のページ番号）
  - 今日の日付（YYYY-MM-DD）
  - `changed` の場合は、既存の `bankFile` を読んで問題 ID を引き継ぐこと（ガイドの「内容が変わった資料」）
  - 書き出したら `node scripts/validate.mjs --quiet` を実行し、その資料のエラーをなくしてから終わること
  - 最後に「資料名・問題数（形式別）・要点数・読めなかったページ」を短く報告すること

## 4. 検査
全資料が終わったら `node scripts/validate.mjs` を実行する。エラーがあれば該当ファイルを直し、合格するまで繰り返す。

## 5. 暗号化して公開
1. `node scripts/build.mjs`
2. `node scripts/publish.mjs "クイズ更新: <科目> <資料名> ほか（+N問）"`
   - 「GitHub の送り先が未設定」「合鍵が未設定」などで送れなかったときは、その旨を報告する（問題データは PC に保存済み）。

## 6. 報告（日本語）
- 資料ごとに: 科目・資料名・問題数（4択／○×／一問一答／国試）・要点数
- 学習内容がないため問題にしなかった資料（講義日程など）とその理由
- 注意点: 読めなかったページ、飛ばした資料、validate の「注意」、置き場所の間違いなど
- **最後の行**に必ず `RESULT: +N問（<科目> <資料名> ほか）` の1行を書く（自動実行の通知に使う）。問題を作らなかったときは `RESULT: 新しい資料はありませんでした`。
