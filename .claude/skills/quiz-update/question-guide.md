# 作問ガイド（1つの資料から問題データを作る）

目的は、薬学部の授業資料の内容を**理解・定着できているか確認すること**。資料に書かれている内容を**漏れなく（網羅的に）**問う。

## 手順

### 1. 資料をすべて読む
- 読む対象は、渡された `items` のファイル（この順番に**すべて**読む）。PowerPoint・Word は変換済みの PDF、長い PDF は10ページずつに分けてある。
- 各ファイルは10ページ以下なので、Read ツールで **`pages` を指定せずに**読む（この PC では `pages` を指定すると読めない）。
- `items[].pages` がそのファイルの元のページ番号（例 "11-20" なら、そのファイルの1ページ目が元の11ページ目）。要点や問題の `pages` には元のページ番号を使う。
- 画像（配布物の写真など）・テキストもそのまま Read で読む。
- 図・表・グラフ・構造式・数式も読み取る。手書きや写りが悪く読めない部分は無理に問題にせず、最後の報告に書く。

### 2. 要点（keyPoints）を作る ＝ 網羅のための一覧
- 試験で問われうる事項を**すべて**列挙する: 定義・分類・名称、構造と性質、反応（試薬・条件・生成物・機構）、作用機序、数値（基準値・定数・単位）、式の意味と使い方、似たものの比較・違い、因果関係、例外、実験法の原理など。
- 1要点＝1つの事実・概念。資料の言葉に沿った短い文にし、ページ番号を付ける。
- 目安はスライド1〜2枚につき1要点。表紙・目次・連絡事項・参考文献は対象外。
- 「重要」「試験に出る」、太字、まとめのスライドなど、授業で強調された箇所は必ず入れる。

### 3. 問題（questions）を作る
- **すべての要点を最低1問で扱う**（validate.mjs が確認する）。重要な要点は形式を変えて2〜3問。
- 問題数はページ数と内容の量に合わせる。目安は10ページあたり5〜10問（90分の講義1回で30〜60問程度）。網羅を優先するが、同じことを言い換えただけの水増しはしない。
- 形式の使い分け:

| 形式 | type | 向いている内容 |
|---|---|---|
| 一問一答 | `flashcard` | 用語・定義・名称・数値など「思い出せるか」。答えは1語〜1文の短いもの |
| ○× | `truefalse` | よくある誤解、似た概念の取り違え、条件の入れ替え。×の文は誤りが1か所に定まるように |
| 4択 | `single` | 理解・適用・比較・計算。誤答は同じカテゴリのもっともらしいものに |
| 国試形式 | `kokushi` | 薬剤師国家試験の形。5つの記述から「正しい（誤っている）のはどれか。1つ（2つ）選べ。」複数の要点を横断してよい |

- 割合の目安: 4択30%・○×25%・一問一答25%・国試20%。内容に合わせて調整してよいが、**4形式すべてを使う**。
- 正解の位置（`answer` の番号）は問題ごとにばらつかせる。特に国試形式は番号が固定されるので偏らないようにする。○× も ○ と × が片寄らないようにする。
- 難易度 `difficulty`: 1＝基本（用語・定義）、2＝標準（理解・比較）、3＝応用（計算・複数の知識の組合せ）。

### 4. 問題文・選択肢のルール
- 答えが1つに定まり、資料の範囲で根拠を示せること。
- 資料にない知識が必要な問題は作らない（高校〜教養レベルの前提知識は可）。資料と一般的な知識が食い違うときは資料に従い、解説で触れる。
- 問題文だけで意味が通じること（「この図の」「上の表で」などに頼らない）。構造式は表示できないので、化合物名・官能基名・特徴を言葉で書く。
- 否定の問いは「**誤っている**のはどれか」のように太字（`**…**`）で強調する。
- 選択肢は長さや書き方をそろえ、正解だけが目立たないようにする。同じ選択肢を重複させない。
- 「上記すべて」「いずれでもない」など並び順に頼る選択肢は使わない（アプリが選択肢を並べ替えるため）。どうしても必要なら `"shuffle": false`。
- スライド番号・先生の名前・日付・出席など、学習内容でないことは問わない。
- 数式は `$…$`（KaTeX）、化学式・反応式は `$\ce{H2SO4}$` のように mhchem を `$` で囲む。上付き・下付きもこれで書く。1つの数式は1行に収める。**JSON の中ではバックスラッシュを2つ重ねる**（`"$\\ce{Br2}$"`、`"$\\frac{1}{2}$"`）。
- 計算問題は2回計算して確かめ、解説に計算の過程を書く。

### 5. 解説（explanation）のルール
- まず正解の根拠（資料の何ページに何とあるか）。
- 4択・国試: 誤りの選択肢それぞれについて、どこが誤りかを短く書く。
  - **4択はアプリが選択肢の順番を入れ替える**ので、解説では番号（①〜④）を使わず、選択肢の中身で示す（例「1-ブロモプロパンは…」）。
  - 国試形式は番号が固定なので「1: 正（p.5）。2: 誤。…」のように番号で書いてよい。
- ○×で×の問題: 正しくはどうなのかを書く。
- 一問一答: 関連事項や覚え方のコツを1つ添えるとよい。
- 2〜6文程度。補足は資料の範囲で。

### 6. 書き出す前の見直し（必ず行う）
各問題について元のページをもう一度見て確認する:
- [ ] 答えが資料と一致している
- [ ] 答えが1つに定まる（国試の2つ選べは、ちょうど2つ）
- [ ] 誤りの選択肢が本当に誤り
- [ ] 問題文だけで意味が通じる
- [ ] 解説の内容が正しく、`pages` が合っている

自信の持てない問題は直すか削除する。

### 7. 書き出しと検査
- 渡された書き出し先（`bankFile`）に UTF-8 の JSON で保存する（フォルダがなければ作られる）。
- `node scripts/validate.mjs --quiet` を実行し、自分の資料のエラーをなくす。

- `materialId` / `term` / `subject` / `sourceFile` / `sourceHash` は scan の結果をそのまま使う。
- `title` は資料の内容から付ける（例「第3回 アルケンの付加反応」）。回数がわからなければテーマだけでよい。
- `id` は `<materialId>-001` から連番。`choices` は4択が4個・国試が5個。`answer` は0から数えた番号の配列（○× だけは true / false）。
- `generatedAt` は初めて作った日。

## 学習内容がない資料の扱い
講義日程・シラバス・連絡事項だけの資料など、問題にできる学習内容がない場合は、問題を作らずに次の形で書き出す（毎回「新しい資料」として扱われ、自動実行のたびに Claude が動いてしまうのを防ぐため）。

```json
{
  "materialId": "（scan の値）", "term": "2A1", "subject": "分子生物学",
  "title": "2026年度 講義日程", "sourceFile": "（scan の値）", "sourceHash": "（scan の hash）",
  "generatedAt": "2026-10-28", "skip": true, "skipReason": "講義日程のみで、学習内容がないため",
  "keyPoints": [], "questions": []
}
```

少しでも学習内容がある資料（まとめプリント、小テストの解説など）は skip にせず、問題を作る。

## 内容が変わった資料（changed）の扱い
- 既存の JSON を読み、新しい資料と照らし合わせる。学習記録は問題 ID にひもづいているので、**まだ正しい問題は ID を変えずに残す**。
- 少し直せば正しくなる問題は、同じ ID のまま直す。意味が大きく変わる場合は古い問題を `"retired": true` にして、新しい ID で作る。
- 資料から消えた内容の問題も削除せず `"retired": true` にする。
- 新しい内容の問題には、既存の最大番号の続きから ID を付ける（番号の再利用は禁止）。
- `keyPoints` も更新する。`generatedAt` は元のまま、`updatedAt` に今日の日付、`sourceHash` を新しい値にする。
