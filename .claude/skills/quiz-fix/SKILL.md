# 報告された問題の修正

## 守ること
- 作業フォルダの外は読むだけ。変更・公開しない。`.secrets/` は読まない。
- 学習記録は問題 ID にひもづいているので、**ID は変えない**。

## 手順
1. 報告から問題 ID（`<materialId>-001` の形）と理由・コメントを取り出す。
2. `quiz-bank/` を ID で検索して、該当する問題とファイルを見つける。
3. 元の資料の該当ページを読んで、報告が正しいか確かめる。
   - `node scripts/prepare.mjs <materialId> --json` を実行し、`items` のうち該当ページを含むファイルを Read で読む（`pages` は指定しない。`items[].pages` が元のページ番号）。
4. 判断して直す:
   - 報告どおり誤り・あいまい → 問題文・選択肢・答え・解説を直す。直しようがなければ `"retired": true`。
   - 解説が不十分 → 解説を補う。
   - 報告が誤解だった → 問題はそのまま。必要なら解説をわかりやすくする。
   - 同じ資料のほかの問題に同じ誤りがないかも確認する。
5. `node scripts/validate.mjs` → `node scripts/build.mjs` → `node scripts/publish.mjs "問題の修正: N件"`
6. 報告ごとに「どう判断し、どう直したか」を日本語で短く伝え、最後にアプリの設定画面で「報告を消す」を押すよう案内する。
